# 卷帙 NovelFolio

离线优先的中文长篇小说创作工作台。人物、世界观、情节、正文、拆书、导入导出——六个入口串成一条从素材到成稿的链路，全部装进一个 105 MB 的免安装 exe。

写长篇最难的不是写，是**记住**：谁在第几章说过什么、这条暗线什么时候该收、人物设定有没有前后矛盾。卷帙把这些拆成结构化数据，让正文、设定、时间线互相对得上；再用「拆书」把现成的整本书反向喂进来，一键长成可编辑的骨架。

**没有账号、没有云、没有埋点。** 数据全在本机，AI 只发给你自己配置的接口。

| | 模块 | 它解决什么 |
| --- | --- | --- |
| 👤 | **人物** | 立绘、人设、身份、目前修为、最终结局；每个人物自带情节时间轴 |
| 🗺 | **世界观** | 多位面舆图，数据驱动的 SVG 多洲地图，宗门节点可拖动、关系线实时重绘 |
| 🧭 | **情节** | 带刻度时间轴 + 多层嵌套暗线，引出点 / 收敛点以树状枝分叉与收敛；滚轮缩放、拖拽定格 |
| ✍ | **章节写作** | 卷·篇目录 + 楷体编辑器；点情节在正文里用「荧光玻璃」标出对应段落；AI 续写进正文 |
| 📚 | **拆书** | 导入整本书 → 自动分章 → 抽人物 / 情节 → 勾选入库 |
| 📥 | **导入导出** | CSV / XLSX / DOCX / MD / TXT 三步向导；JSON 整库导出与恢复；自动备份 |
| 🎨 | **生图** | 一键拼提示词 → 打开生图网站 → 把图拖回来设成立绘 |

**这一版**：新建章节弹窗可自选「第几章 + 标题名」（号已有则插入、其后顺延）；点章节行收起 / 展开该章情节；点情节在正文里亮起一层暖琥珀「荧光玻璃」，只加底色、不碰文字、再点即收起。

**隐私**：API Key 只存本机 `secrets.bin`（DPAPI 加密），视觉上永远只显示掩码；无账号、无埋点、无上报。任何 OpenAI 兼容接口都能接（OpenAI / DeepSeek / 通义 / 智谱 / Kimi / Ollama…）。

**技术栈**：Electron 45 + 原生 ES 模块，零前端依赖、无打包器；数据为单个 JSON 原子写 + 自动备份。MIT 许可，仅限 Windows 打包。
